## 📊 Featured Projects

### 1. Bellabeat Consumer Insight Analysis (Google Data Analytics)
* **The Goal:** Analyze smart device fitness data to identify trends in user activity and sleep patterns.
* **The Impact:** Formulated strategic recommendations for Bellabeat’s marketing team to enhance global user engagement.
* **Skills:** Python, Data Wrangling, Merging disparate datasets.

### 2. AiRcruit – Recruitment System (Graduation Project)
* **The Goal:** Developed the backend system for the recruitment platform.
* **The Impact:** Successfully linked complex user inputs to a central database, facilitating iterative development and UI customization.
* **Skills:** Backend Development, Database Management, Django, Python.

### 3. Movie Industry Revenue Analysis (Udacity)
* **The Goal:** Investigated a large-scale movie dataset to determine which factors (budget, genre, release date) most influence revenue.
* **The Impact:** Provided data-backed insights into industry trends to optimize production budgets.
* **Skills:** Exploratory Data Analysis (EDA), Data Visualisation.

### 4. US Bikeshare Pattern Discovery (Udacity)
* **The Goal:** Analysed urban mobility data from major US cities to identify peak usage times and station popularity.
* **The Impact:** Delivered a comprehensive business overview of urban transit patterns using Python.
* **Skills:** Python, Scripting, Descriptive Statistics.
